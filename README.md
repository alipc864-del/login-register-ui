# 🔐 Login & Register UI

A modern and responsive login and registration UI built with HTML, CSS and JavaScript.

## ✨ Features

- 🔐 Login form
- 📝 Registration form
- 🔄 Switch between Login and Register
- 👁️ Show and hide password
- ✅ Form validation
- ⚠️ Error messages
- 📱 Responsive design
- ✨ Modern dark UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 About

This project was created to practice JavaScript, DOM manipulation, form validation and responsive web design.
